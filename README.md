# Saints Label landing

Vite + React + TypeScript marketing site for the Saints Label Bible Study Guide Journal.

## Static Quiet Hour variant

A plain HTML/CSS/JS version of the Quiet Hour lander lives in `public/quiet-hour-static/`.

- `/quiet-hour-static/` — static audio version.
- `/quiet-hour-static/quiet-hour.html` — static no-audio version.
- `/quiet-hour-static/quiet-hour-2.html` — static audio version.

These files are intentionally separated from the React routes so `/`, `/quiet-hour`, and `/quiet-hour-2` keep their current app behavior.
